brainCloud C# Client Library

This package includes the brainCloud C# Client source code. For non-Unity versions of your client apps, you can include this source in Visual Studio, VS Code, or Godot to make use of our APIs. You can add the project via the BrainCloud.sln Solution or just add the source files under the BrainCloud folder directly.

The GitHub's README.md contains much useful information! If this is your first time using this library then we strongly recommend you giving it a read:

https://github.com/getbraincloud/braincloud-csharp?tab=readme-ov-file#readme

Also check out our examples for real-world use cases:

C# Examples: https://github.com/getbraincloud/examples-csharp
Unity Examples: https://github.com/getbraincloud/examples-unity?tab=readme-ov-file#readme

For more information about brainCloud and the client library including Release History, API Documentation, and Tutorials please visit:

https://docs.braincloudservers.com/learn/introduction/

If you need help you can reach out to us by logging into the brainCloud Portal and hitting the blue "Ask Support" button on the top-right, next to your profile icon!

Thanks and happy coding!
- The brainCloud Team
